# Friendship with God Card – Test

## Test 1: Generate Card
1. Enter a recipient name.
2. Enter your name.
3. Add a personal message.
4. Select an occasion and theme.
5. Click **Generate Card**.

**Expected Result:**  
The card displays the selected occasion, personal message, sender name, and theme.

## Test 2: Empty Names
1. Leave recipient and sender empty.
2. Click **Generate Card**.

**Expected Result:**  
The card uses **Friend** and **Your Friend** as default names.

## Test 3: Change Theme
1. Select **Ocean**.
2. Click **Generate Card**.

**Expected Result:**  
The card changes to the `card--ocean` theme.
